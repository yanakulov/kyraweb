# Субтитры и тайминг интро

**Язык:** [English](subtitles.md) | Русский

Письмо Каллака, сцена у дерева и разговор Каллака с Малкольмом используют общую шкалу кадров и реплик. `introTimeline.json` содержит изменения кадров, положения руки, координаты текста и команды его удаления из DOS floppy-последовательностей. При расчёте учитываются циклы, ожидания в тиках 60 Гц и пауза ScummVM 8 мс после каждой команды. Реплики больше не растягиваются под количество PNG-кадров.

Пересоздание: `node extractor/intro_timeline.mjs /path/to/lok_dos.h`. Источники: [DOS-последовательности](https://github.com/scummvm/scummvm/blob/master/devtools/create_kyradat/resources/lok_dos.h) и [SeqPlayer](https://github.com/scummvm/scummvm/blob/master/engines/kyra/sequence/seqplayer_lok.cpp). Английский текст хранится отдельно в `introText.json`.

Проигрыватель передаёт активные реплики в DOM и очищает их в паузах, на смене сцены, остановке и пропуске. Отрисовка текста на canvas включается отдельно. DOM-текст размещается в координатах 320×200, ограничивается краями экрана и масштабируется вместе с canvas. Разговорный текст привязан нижним краем; письмо начинается на y=180.

Главное меню повторяет первый цикл письма без реплик. После старта письмо проигрывается целиком со всеми четырьмя строками. Выбор сцены в отладке работает без меню. Рука и фон синхронизированы.

Проверки: `npm test`, `npm run typecheck`, `npm run build`. Это тайминг DOS-версии с текстом, без синхронизации CD-озвучки. Длительности переходов палитры, постепенное появление букв и смещения имеющихся PNG пока не являются попиксельной реализацией ScummVM.
