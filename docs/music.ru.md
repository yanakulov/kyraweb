# Музыка MT-32

В DOS CD-версии GOG музыка хранится в `DAT/XMI.PAK`, а не на аудиодорожках CD.
Веб-версия проигрывает оригинальный XMIDI через эмулятор **Munt / libmt32emu**.
Это синтез Roland MT-32 / CM-32L, а не замена инструментов на General MIDI.

## Как включить

**На этом компьютере импорт больше не нужен.** Совместимая пара уже лежит
в `.local/mt32/` и автоматически подхватывается при `npm run dev` или
`npm run preview` через localhost. Открой книгу — это обычное разрешающее действие
для звука в браузере. Если ранее явно выбрано «Без музыки», включи MT-32 в настройках.

ROM исключены из Git, `public/` и `dist/`. Локальный сервер отдаёт их только
клиентам localhost своего происхождения; публикация сайта их не включает.
Для опубликованного сайта остаётся ручной импорт:

1. Открой книгу → **Настройки**.
2. Нажми **Импортировать пару ROM** и выбери сразу два собственных файла:
   **Control ROM** (64/128 КиБ) и **PCM ROM** (512/1024 КиБ).
3. После проверки файлов музыка включится. **Проверить музыку** проиграет тему
   заставки, даже когда сама игра стоит на паузе в меню.
4. Настрой громкость. Выход из настроек останавливает проверку и возвращает
   музыкальное сопровождение игры.

ROM-файлы Roland **не входят в GOG-версию** и не распространяются с проектом.
Нужна собственная правомерно полученная совместимая пара. Файлы остаются только
в IndexedDB этого браузера: на сервер они не отправляются. Кнопка **Удалить ROM**
убирает сохранённую пару. Ошибка нового импорта не заменяет рабочие файлы.

Для звука требуется действие пользователя, современный браузер с AudioWorklet
и WebAssembly, HTTPS или localhost. Устройство и громкость запоминаются отдельно
от сохранений игры. Музыка останавливает свой таймер в Options и при загрузке;
при скрытии вкладки звуковой контекст приостанавливается.

## Обновление игровых ресурсов

```powershell
npm run assets:music -- "C:\Program Files\GOG Galaxy\Games\Legend of Kyrandia"
```

Экспортируются десять оригинальных XMI без потерь, с контрольными суммами.
ROM в экспорт не попадают. Исходники Munt, лицензии и рецепт сборки включены
в отдельный архив рядом с WASM; игра автоматически этот архив не загружает.

## Что пока не сделано

- Озвучка VOC и AdLib/Sound Blaster.
- Продолжение музыки с точного сэмпла при загрузке главы: тема начинается заново.
- Посэмпловое совпадение музыкальных переходов с исходным DOS-интро.
- Сравнение с физическим Roland MT-32. Синтез с локальной ROM-парой уже проверен:
  настоящий AudioWorklet выдаёт звуковой сигнал; первый сигнал зафиксирован через
  613 мс после запуска. Молчаливая настройка тембров больше не занимает 14 секунд.

Проверены разбор всех 1120 последовательностей, таймер нот, циклы, SysEx,
музыкальные команды сцен и загрузка настоящего WASM в AudioWorklet с отклонением
невалидных ROM. Подробности архитектуры и лицензий: [music.md](music.md).

## Звуковые эффекты

Подключены оригинальные SFX из XMI: взятие и обмен предметов, инвентарь,
отскок и приземление, невозможность броска, команды EMC/DAT и эффекты интро.
Музыка и до трёх эффектов одновременно используют один MT-32 с исходным
переназначением MIDI-каналов. Музыка при этом не запускается заново.

В настройках есть отдельные «Звуковые эффекты» и «Громкость эффектов».
SFX работают даже при выборе «Без музыки». Звук взятия предмета проверен
в настоящем AudioWorklet с выключенной музыкой. Озвучка диалогов пока не подключена.
