# Передвижение и walkmask

**Язык:** [English](movement.md) | Русский

Передвижение использует сетку LoK 4×2 пикселя и восемь направлений. Координаты клика округляются вниз до сетки перед поиском пути: дробные координаты браузера больше не вызывают перескок и колебания возле цели. Поиск пути использует оригинальный выбор направления, обход препятствия с двух сторон, выбор более короткого обхода и сокращение возвратов. Лимит — 150 шагов. Источник: ScummVM `engines/kyra/engine/scene_v1.cpp`, GPL-3.0-or-later; текст лицензии в `LICENSES/GPL-3.0.txt`.

Маска — `public/assets/masks/<SCENE>.json`, блокирующий бит — 0x80. Проверяется ширина опоры персонажа при стандартном масштабе LoK и реальные границы маски. Направление меняется по сегментам пути. Таймер ходьбы не зависит от рендера: существующие режимы используют 11/9/6/3 тика при частоте 60 Гц. За шаг персонаж проходит 4 пикселя по горизонтали, 2 по вертикали либо оба расстояния по диагонали.

Кадры ходьбы Брендона: 8–14 вбок, 29–34 вниз и 35–40 вверх. Они находятся по `shapeIndex` в атласе. По умолчанию кадр меняется на каждом шаге, остановка использует shape 7. Передний план кэшируется по слою персонажа, без чтения пикселей canvas на каждом кадре.

Дроп проверяет отдельную опору шириной 16 пикселей, слой пола, занятые позиции и лимит 12 предметов на сцене. Падение начинается с 2 пикселей за тик, ускоряется на 1 и имеет не более одного отскока по правилам `items_lok.cpp`. Предмет приземляется точно в выбранную позицию. Неудачный дроп сохраняет предмет в руке; клик по другому предмету меняет их местами. До завершения падения повторные клики блокируются.

Реализована GEMCUT при стандартном масштабе персонажа. Для зон запрета дропа, оригинальных высот отдельных предметов, выходов и скриптовых переходов ещё нужны соответствующие данные сцены; сейчас при дропе учитывается иконка высотой 16 пикселей. Это не полная замена скриптового движка Kyrandia.

Проверки: `npm test`, `npm run typecheck`, `npm run build`. Тесты охватывают настоящую маску GEMCUT, наклонные и диагональные маршруты, препятствия, заблокированные цели, номера кадров, смену цели, обмен предметов и одинаковый тайминг ходьбы/дропа при 30/60/144 Гц.
