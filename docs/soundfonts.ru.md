# Другие варианты звука: SoundFont

В **Настройках → Музыкальное устройство** теперь два разных пути синтеза:

- **Roland MT-32 / CM-32L · Munt** — существующий эмулятор Roland с ROM.
- **SF2 · название банка** — TinySoundFont/WebAssembly с настоящими сэмплами
  выбранного банка. ROM Roland для этого режима не нужны.

**GeneralUser GS 2.0.3** (S. Christian Collins) доступен и на GitHub Pages.
Браузер скачивает банк (32,3 МБ) при его выборе. Выбери его и
нажми **Проверить музыку**, чтобы сравнить с Munt. Музыка, SFX, их отдельная
громкость и пауза работают через выбранный движок. Смена движка начинает текущую
тему заново, не меняя состояние игры.

## Добавить свои банки

**Добавить банк SoundFont (.sf2)** принимает файлы до 64 МиБ. Каждый банк
появляется отдельным пунктом; имя берётся из имени файла. Файл хранится в
IndexedDB этого браузера и не загружается на сервер. При недоступном хранилище
банк работает до закрытия страницы с предупреждением. Неправильный SF2 не
заменяет работающий движок. Выбор банка запоминается отдельно от сохранений игры.

При локальной разработке можно положить банки в `.local/soundfonts/`: каталог
обнаруживается автоматически. Локальный сервер принимает до 32 файлов с простыми
латинскими именами `.sf2`. Банки загружаются только при выборе; даже большой набор
не увеличивает начальную загрузку игры. Прямой доступ к `.local` и запросы извне
localhost заблокированы. В `dist/` банки не копируются.

## Важное ограничение

Это **не готовая аппаратная эмуляция MU50, Kawai CCP-014, Casio SZ-50V, Sound
Saurus или SBLive CT4830**. Для характерных наборов инструментов этих устройств
нужны соответствующие совместимые SF2-банки; их происхождение и права проверяются
отдельно. Загрузка банка не эмулирует DSP, EAX, XG-эффекты или электронику карты.
Пустых пунктов с названиями карт и одинаковым звуком нет.

Кирандия 1 содержит MT-32 XMIDI, но не отдельную GM/XG-аранжировку. В SF2-режиме
используется приближённое преобразование 128 программ MT-32 → GM из ScummVM.
Roland SysEx не посылается в SoundFont. Специальные тембры и SFX могут звучать
иначе или неточно; для оригинального звучания оставляй Munt. Банк GeneralUser GS
не выдаётся за Yamaha, Kawai или Creative.

## Размер и проверка

Публичный GeneralUser GS загружается отдельно от игры. Для установки ещё одной
локальной копии можно использовать:

```powershell
node extractor/vendor_soundfont.mjs --local-bank
```

Скрипт проверяет закреплённые Git-хеши WASM и банка. Лицензия GeneralUser GS
сохранена рядом; она разрешает применение в программных проектах и содержит
оговорку автора о происхождении части старых сэмплов. Лицензия и точная версия публичного банка указаны в `public/assets/audio/README.md`.
Другие банки доступны через локальный импорт.

Проверены настоящий TinySoundFont WASM, непустой PCM, импорт повреждённого файла,
выбор банка, возврат на Munt и ограничения локального сервера. Одна исходная
тема через GeneralUser GS и Munt даёт разные аудиоданные. В браузерном
AudioWorklet GeneralUser GS также выдаёт ненулевой сигнал (RMS 0,00303 в проверке).
