# Kyrandia Web

A browser reimagining of The Legend of Kyrandia, Book One of Fables & Fiends. The experience serves players who want the original adventure's scenes, dialogue, animation and point-and-click interaction on desktop and touch screens.

## Product commitments

- Preserve the original game's pixel art, story, scene geometry and gameplay behavior. Keep controls within the adventure and its book, with no external masthead, toolbar or footer.
- Present Book One as a tactile antique book on a fullscreen aged wooden desk: coarse horizontal boards, knots and scars, rich oxblood leather and worn gilding with patina. Emboss a cleaned version of the user-supplied original cover composition into its leather. Only The Legend of Kyrandia title remains on the cover; retail logos, rating and edition labels are removed with ImageGen. The edited illustration is not a pixel-identical reproduction of the supplied scan.
- Opening the cover reveals bare parchment. Contours and a soft tonal wash draw the original intro landscape into the lit paper, with sparse hatching and a small gold trace. On the first visit, the open book offers a skippable four-page prehistory before the picture gains color and the camera enters it. Keep the book visible until the intro's first frame is ready, then continue with Westwood and the AkulaFlow studio mark over that same landscape. At Kallak, the camera pulls back into the book's main menu.
- Make the main action clear at every stage: Open the book, Start Journey, then explore. The book's main menu offers Start Journey, Load game, Settings and How to play. The original HUD Options button pauses the adventure and pulls the current frame back into a fullscreen book spread: controls on the left, a recognizable ink illustration of the location and characters on the right, without the HUD. Resume restores the complete captured frame before the game clock restarts. Inventory remains in the original game HUD; credits belong inside book Settings.
- Offer English and Russian text, selected in book Settings and remembered in this browser. Default to the browser's language on the first visit. Translate the implemented intro, opening and forest dialogue, location and item names, letter and interface without changing original script strings or animation timing. Use book-styled keyboard-accessible dropdowns and readable Cyrillic. The story so far in Settings reopens the prehistory.
- Offer three named manual save slots in this browser and on this device, each with location, time and a scene thumbnail. Save the full world state, including visited rooms, inventory, quest flags, NPCs, scene animation state and gameplay settings. Continue journey opens the latest valid save; Load game allows a specific chapter. Confirm replacement, report damaged slots or blocked/full storage, and preserve existing data when an operation fails.
- Keep the table dim, with warm candlelight and a subtle local glow following the magical book cursor. Let the visible candle and light move together at up to 30 rendered frames per second, with full refresh during camera transitions. Stop rendering while the document is hidden; reduced motion uses a static candle and bypasses book transitions and decorative interface motion.
- Desktop uses the original cursor, including over the HUD Options button. Touch uses a persistent cursor guided by swipes, with a tap to interact. Dialogue taps skip the current line. Preserve pinch zoom and usable inventory targets.
- Keep download size measured. Original graphics use indexed scene packs; new interface illustrations use compressed WebP. Three.js is confined to the book presentation. Measure the complete production build and packed book model separately after changes; neither has a fixed size promise.

## Authority and scope

The user's direction is old Kyrandia: restrained fantasy materials, gems, pixel graphics and a real three-dimensional opening book. The implemented references are `src/App.vue`, `src/styles.css`, `src/components/FantasyBook.vue`, `src/components/BookMenu.vue`, `src/components/BookSelect.vue`, `src/components/BookPrologue.vue`, `src/components/prologue.ts`, `src/components/storybookInk.ts`, `src/components/bookTransition.ts`, `src/i18n.ts`, `src/locales/ru-game.json`, `src/engine/gameplay/saveStorage.ts` and `src/engine/intro/steps.ts`. The Blender source recipe is `extractor/model_storybook.py`, with the cleaned illustration at `extractor/materials/cover-illustration.png`; the browser loads `public/assets/interface/storybook.glb.gz`. The editable `.blend` remains in ignored `.reference/`. `DESIGN.md` documents the visual system and prehistory sources.

The user's preferred aged desk texture is restored from the earlier generated `desk.webp` into `extractor/materials/aged-walnut.webp`. Blender embeds it in the GLB; it is not a separate runtime download.

Original game credit remains Westwood Studios (1992); web remake credit remains Yan Akulov. The AkulaFlow mark is a new studio presentation based on the local brand reference at `../akula-flow/public/brand/identity.png`.
